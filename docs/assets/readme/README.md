# README figures

These are repository-owned SVGs used by the root README. They are deliberately redrawn at README scale instead of shrinking a full paper figure: labels are larger, the number of visual elements is smaller, and the logical/physical distinction is readable without opening the paper.

- `paper-motivation.svg` is a README-specific adaptation of the paper's lineage and batching discussion in `RayOrch-Arxiv/figures/teaser_lineage_pipeline_v2.tex`.
- `paper-program-execution.svg` is a README-specific adaptation of the paper's program/control-plane/execution-plane discussion in `RayOrch-Arxiv/figures/pdf_workflow_refined.tex`.
- `mineru-comparison.svg` is a vector render of the paper's existing `RayOrch-Arxiv/figures/mineru_three_system_timeline.pdf`, comparing the cold end-to-end MinerU timeline for RayOrch, Ray Data, and Daft.

The diagrams explain the programming model and the reported benchmark setup. They are not a substitute for the [full paper](https://arxiv.org/abs/2609.18703) or the [benchmark documentation](https://opendcai.github.io/RayOrch-doc/en/benchmarks/).
