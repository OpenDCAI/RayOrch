## 4. 与 MSR-VTT 的差别

MSR-VTT 1.3GiB 实验中：

```text
parent frames/RPC        10.48
elastic frames/RPC       15.67
elastic speedup          1.159×
```

UCF101 中单个 parent 已经经常接近 batch cap：

```text
parent frames/RPC        14.45
elastic frames/RPC       15.87
elastic speedup          1.024×
```

因此收益由 **fan-out 分布相对 batch cap 的位置** 决定。若 parent 自身已能形成满 batch，
cross-parent rebatching 只剩尾部小空间；这正是需要同时报告 batch histogram 的原因。

## 5. 结论

该 4GiB 实验满足原计划的数 GB、数百以上独立公开视频要求，并验证：

- V3 elastic 在高 parent fill 的 workload 上仍有小幅正收益；
- 收益从 MSR-VTT 的约16%降到 UCF101 的约2.4%，符合可解释的 packing 上限；
- “elastic 是否有用”不能只看数据规模，必须看 parent fan-out 与 model batch cap 的关系。

由于单 pair 已耗时约70分钟，本结果作为规模确认；稳定统计主结果仍采用两轮 MSR-VTT。
